！！！注意： 查询，变更和删除用户资料时必须添加上token，token在验证登录时生成！！！
!!! You can get a token through Login, and use it to get profiles, update and delete !!!
Examples: 

1, 用户注册 Registration：
curl -X POST http://localhost:8000/register \
  -H "Content-Type: application/json" \
  -d '{"username": "api_tester_1", "password": "123", "nickname": "Original Name"}'
1,预期结果 Output：
{"msg":"注册成功"}


2, 用户登录 Login：
curl -X POST http://localhost:8000/login \
  -H "Content-Type: application/json" \
  -d '{"username": "api_tester_1", "password": "123"}'
2, 预期结果 Output：
{"msg":"登录成功","token":"<生成的token>"}


3, 用户查询资料 Get Profiles：
curl -X GET http://localhost:8000/user/profile \
  -H "Authorization: Bearer <在此处粘贴Token>"
3, 预期结果 Output:
{"username":"api_tester_1","nickname":"Original Name"}


4, 用户更新资料 Update Profiles：
curl -X PUT http://localhost:8000/user/profile \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <在此处粘贴Token>" \
  -d '{"nickname": "Updated Reg Master", "email": "reg@test.com"}'
4, 预期结果 Output：
{"msg":"资料更新成功"}


5, 用户删除资料 Delete Profiles：
curl -X DELETE http://localhost:8000/user/10 \
  -H "Authorization: Bearer $MY_TOKEN" 

5, 预期结果 Output：
{"msg":"用户删除成功"}
