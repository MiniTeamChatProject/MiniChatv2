# web-vue

> ⚠️ **注意：这是一个用于测试的最简陋版本前端**

## 说明

这是一个**仅供开发测试使用**的 Vue 3 前端项目，用于验证 Room Service 的功能。

**特点**：
- ✅ 最小化功能实现
- ✅ 快速开发原型
- ⚠️ 代码质量较低
- ⚠️ 缺少完善的错误处理
- ⚠️ 不适合生产环境

## 技术栈

- Vue 3 (Composition API)
- TypeScript
- Vite
- TailwindCSS
- Axios

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 功能

- 用户登录/注册
- 房间列表
- 创建房间
- 加入/离开房间
- 实时聊天（WebSocket）
- 消息历史

## 环境变量

创建 `.env.local` 文件：

```bash
# API 基础地址
VITE_API_URL=/api

# WebSocket 地址
VITE_WS_URL=ws://localhost:8001
```

## 已知问题

1. **用户名显示**：历史消息的用户名显示不完整（后端 API 限制）
2. **错误处理**：部分错误情况处理不够完善
3. **状态管理**：使用简单的全局状态，未引入 Vuex/Pinia
4. **样式**：使用 TailwindCSS 但样式较简单
5. **测试**：无单元测试
